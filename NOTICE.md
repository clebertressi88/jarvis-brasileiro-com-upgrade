# Aviso de origem

Projeto derivado de
[tudormatei/jarvis-local](https://github.com/tudormatei/jarvis-local).

Esta versão acrescenta localização em português, interface flutuante,
ferramentas locais, agentes especializados, memória e controles adicionais de
segurança. Nenhum histórico Git do computador usado para preparar esta versão
foi incluído.
